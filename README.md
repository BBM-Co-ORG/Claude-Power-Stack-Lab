# labshop — สนามฝึกของ Claude Power Stack

ระบบออกใบแจ้งหนี้อย่างง่ายสำหรับธุรกิจไทย **โค้ดชุดนี้จงใจมีข้อบกพร่องฝังอยู่**
ห้ามนำไปใช้งานจริง มันมีไว้ให้ฝึกทำงานกับ agent บนโค้ดที่พังจริง ไม่ใช่ตัวอย่างที่สวยงาม

## เริ่มต้น

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e . pytest
pytest -q
```

ผลที่ควรเห็นตอนเริ่ม: **7 ไม่ผ่าน · 12 ผ่าน** ถ้าเลขไม่ตรง ให้ดูว่ารันด้วย Python 3.10 ขึ้นไปหรือยัง

## กติกาของสนามนี้

1. **อย่าไล่ดูทีละไฟล์เอง** เป้าหมายคือฝึกให้ agent หาให้ ไม่ใช่ฝึกอ่านโค้ดด้วยตา
2. **บั๊กบางตัวไม่มีเทสจับ** มันมาในรูปใบแจ้งปัญหาจากลูกค้าข้างล่าง เหมือนงานจริง
3. **เทสที่ผ่านไม่ได้แปลว่าโค้ดถูก** มีอย่างน้อยหนึ่งจุดที่เทสเขียนค่าที่ผิดเอาไว้เอง
4. **อย่าแก้เทสที่ไม่เสถียรด้วยการรันซ้ำจนผ่าน** ให้หาว่าทำไมผลถึงไม่คงที่

## ใบแจ้งปัญหาจากลูกค้า — ของจริงที่ต้องแก้

> **#1 · ฝ่ายบัญชี** ยอด VAT ในใบแจ้งหนี้ไม่ตรงกับที่โปรแกรมบัญชีคำนวณ ต่างกันหนึ่งถึงสองสตางค์
> เฉพาะใบที่มีหลายบรรทัด ใบบรรทัดเดียวตรงหมด

> **#2 · ลูกค้าองค์กร** "ยอดที่ต้องโอนในใบแจ้งหนี้สูงกว่าที่ตกลงกันไว้" — เขาบอกว่าภาษีหัก ณ ที่จ่าย
> ต้องคิดจากค่าบริการ ไม่ใช่จากยอดที่รวม VAT แล้ว **หมายเหตุ: เทสของเราผ่านหมดในส่วนนี้**

> **#3 · ฝ่ายขาย** หน้ารายการใบแจ้งหนี้แสดงไม่ครบ ใบล่าสุดหายไปสองสามใบ
> พอลองนับเองพบว่ามี 23 ใบ แต่ระบบแสดงแค่ 20

> **#4 · ลูกค้าที่ส่งไฟล์มาให้นำเข้า** ระบบขึ้น error ตอนอัปโหลด ไฟล์เปิดใน Excel ได้ปกติ
> (ลูกค้ารายนี้ใช้ Excel ภาษาไทยรุ่นเก่า)

> **#5 · ฝ่ายบัญชี** ใบที่ระบุวันที่เป็น พ.ศ. บางใบแปลงปีไม่ถูก โดยเฉพาะใบเก่า ๆ

> **#6 · ลูกค้า** วันครบกำหนดชำระคลาดไปหนึ่งวัน เกิดเฉพาะใบที่ออกตอนเช้ามืด

> **#7 · ฝ่ายบัญชี** ยอดค้างชำระของลูกค้ารายหนึ่งพองขึ้นเรื่อย ๆ ทั้งที่ไม่มีใบใหม่
> เกิดเฉพาะตอนที่ระบบประมวลผลหลายใบติดกัน

> **#8 · ทีมพัฒนา** เทสตัวหนึ่งบางรอบผ่าน บางรอบไม่ผ่าน ทั้งที่ไม่มีใครแก้โค้ด
> ตอนนี้ทีมเริ่มชินกับการกด re-run

> **#9 · ฝ่ายนำเข้าข้อมูล** พอ import ไฟล์ที่มีแถวเสียหลายรอบติดกัน รายการ error ที่ระบบรายงาน
> ยาวขึ้นเรื่อย ๆ รวมแถวของไฟล์ก่อนหน้าเข้ามาด้วย **ไม่มีเทสจับจุดนี้**

> **#10 · ฝ่ายขาย** ลูกค้าที่สั่งพอดี 100 ชิ้นไม่ได้ส่วนลดขั้น 100 ชิ้น ต้องสั่ง 101 ถึงจะได้
> โค้ดส่วนนี้อยู่ในไฟล์เก่าที่ไม่มีใครกล้าแตะ **ไม่มีเทสจับจุดนี้**

## ใบงานแยกตาม track

### นักพัฒนาที่เพิ่งเริ่ม

1. **งานอุ่นเครื่อง** เลือกใบแจ้งปัญหา #3 หรือ #4 — ชี้ไฟล์ที่เกี่ยวข้องให้ครบแล้วให้ agent หาสาเหตุ
   สังเกตว่าการวางข้อความ error จริงกลับเข้าไป ได้ผลดีกว่าการเรียบเรียงคำถามใหม่
2. **ตั้งเงื่อนไขจบแล้วปล่อยงาน** ตั้งเงื่อนไขที่พิสูจน์ได้จาก `transcript` เช่น "เทสใน `tests/` ผ่านทั้งหมด"
   แล้วเดินออกจากคีย์บอร์ด — ห้ามตั้งว่า "ทำให้โค้ดดีขึ้น"
3. **สร้าง `verifier` แบบไม่เห็นเหตุผลเดิม** ให้ตรวจงานที่เพิ่งแก้ **เป้าหมายคือให้มันจับใบแจ้งปัญหา #2 ได้**
   ซึ่งเทสทั้งหมดผ่านอยู่ เพราะเทสเขียนค่าที่ผิดเอาไว้เอง
4. **ใบแจ้งปัญหา #8** อย่าแก้ด้วยการรันซ้ำ ให้หาสาเหตุของความไม่คงที่

### หัวหน้าสายเทคนิค

1. **เขียน `CLAUDE.md` ของ repo นี้** — คำสั่งรันเทส โครงสร้าง และกติกาว่าห้ามแก้อะไร
   เกณฑ์: สั้นกว่าสองหน้าจอ และทุกบรรทัดต้องเป็นสิ่งที่ถ้าไม่เขียนแล้วจะโดนถามซ้ำ
2. **`src/labshop/legacy_pricing.py`** ไม่มีเอกสารเลยและถูกเรียกจากสองที่
   ให้ agent อธิบายว่ามันทำอะไรและถูกเรียกจากไหน **ก่อน** สั่งแก้ — แล้วค่อยแก้ใบแจ้งปัญหา #10
3. **เขียน skill หนึ่งตัว** เช่น `/ship` ที่รันเทสและตรวจก่อน commit แล้วส่งให้เพื่อนในห้องลองรัน
4. **ตกลงด่านรีวิว** สำหรับโค้ดที่มาจาก agent ใน repo นี้ แล้วเขียนลงเป็นกฎจริง

### ผู้บริหาร (ไม่ต้องเขียนโค้ด)

1. เปิดใบแจ้งปัญหา #2 กับ #9 แล้วถามว่า **"ถ้าสองอันนี้หลุดขึ้นระบบจริง ใครเป็นคนรับผิดชอบ"**
2. ใช้ใบแจ้งปัญหา #2 เป็นตัวอย่างของ "เทสผ่านแต่ผลผิด" — นี่คือเหตุผลที่ด่านตรวจสอบ
   ต้องไม่ใช่แค่ "CI เขียว"
3. กรอกแบบฟอร์มรับ use case โดยสมมติว่าจะให้ agent แก้บั๊กใน repo นี้อัตโนมัติแล้ว merge เอง
   — จะได้ระดับความเสี่ยงเท่าไหร่ และต้องผ่านด่านอะไรบ้าง

## โครงสร้าง

```
src/labshop/
  models.py           โครงข้อมูลใบแจ้งหนี้
  tax.py              VAT และภาษีหัก ณ ที่จ่าย
  dates.py            แปลง พ.ศ. และคำนวณวันครบกำหนด
  importer.py         นำเข้าจาก CSV
  pagination.py       แบ่งหน้า
  ledger.py           ยอดค้างชำระรายลูกค้า
  legacy_pricing.py   ส่วนลดตามจำนวน — ไม่มีเอกสาร
tests/                เทส (บางตัวไม่ผ่าน บางตัวไม่เสถียร บางตัวเขียนค่าผิดไว้)
data/                 ไฟล์ CSV ตัวอย่าง รวมไฟล์ที่ไม่ใช่ UTF-8
```
